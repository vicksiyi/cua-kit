# 持久 JavaScript 会话的生命周期与取消

QuickJS 单元保留顶层变量。每个单元串行执行；成功返回前等待它发起的宿主工具调用收敛，即使调用未被 await。此约束避免上一单元的截图、文字或动作混入下一单元。

## 超时与 reset

每个单元绑定 AbortController 与运行代次。MCP 请求取消传递到运行时；reset/close 会先取消当前单元，再进入串行清理。超时或中断要求 reset，旧代次的桥接回调不能写入新会话。SDK 创建/绑定目标也检查代次与取消信号：旧请求等待授权期间发生 reset，授权随后返回也不得创建页面。

reset 清除 JS globals、句柄和 VM，保留已拥有的浏览器页面；close 释放浏览器与原生 helper。关闭后不得用 reset 复活 VM。正在等待的授权回调本身属于宿主，CUA 无法强行终止其代码；跨 reset 的未完成宿主调用仍计入并发额度，最多 64 个，防止靠重复 reset 绕过上限。

取消不是回滚。已发出的输入、导航或原生调用可能已经发生，必须重新观察，不自动重放。同步 QuickJS 运算阻塞 Node 事件循环期间，外部取消消息不能即时处理；引擎中断处理器仍按墙钟 deadline 检查。线程/进程级调度隔离和更多恶意负载压力验收仍待完成。

## 额度

- QuickJS 内存 32 MiB，栈 512 KiB。
- 单元源码最多 100000 字符；宿主能力请求最多 1 Mi 字符。
- 活跃宿主请求跨代次最多 64 个。
- 输出额度 8 MiB，文本按 UTF-8 字节计数，图片按 base64 数据长度计数。
- 单元最长 60 秒；默认 20 秒。

没有注入 Node process/require/fs/fetch，模块导入被禁用。这是有限的引擎隔离，不是操作系统沙箱或多租户安全承诺。

## 回归证据

`tests/runtime.test.ts` 验证：未 await 的创建任务在单元返回前完成；授权被挂起后发生超时/reset，随后放行也不会新建页面；新单元输出无旧内容；外部取消与 reset 能终止未决 Promise；过大源码和 Unicode 输出按预算拒绝；关闭后不可复活。

`tests/agent.test.ts` 通过真实 MCP stdio 客户端取消执行，再 reset，验证不必等待原 20 秒 deadline。整体测试当前 11 passed、1 原生 fixture skipped。更多并发/崩溃/导航中的取消场景仍需补齐。
